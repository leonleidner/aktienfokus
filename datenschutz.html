5. Anwendung „AktienFokus Upload“ (YouTube API Services)

AktienFokus Upload ist eine interne Anwendung, die ausschließlich der Betreiber nutzt, um Videos auf den eigenen YouTube-Kanal AktienFokus hochzuladen. Die Anwendung nutzt die YouTube API Services. Für die Nutzung gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Welche Daten verarbeitet werden

  • ein OAuth-Zugriffstoken für das Google-Konto des Kanals, das bei der Anmeldung über Google erteilt wird
  • Name und ID des eigenen YouTube-Kanals
  • die IDs der hochgeladenen Videos und die Inhalte, die hochgeladen werden: Video, Titel, Beschreibung, Thumbnail, Untertitel, Veröffentlichungstermin

Wofür und wo

Die Daten dienen nur dazu, Videos auf den eigenen Kanal hochzuladen und ihre Angaben zu setzen. Das Token und die Video-IDs werden ausschließlich lokal auf dem Rechner des Betreibers gespeichert. Es gibt keinen eigenen Server, keine Weitergabe an Dritte, keine Werbung und keine Auswertung. Daten anderer YouTube-Nutzer werden weder abgerufen noch gespeichert.

Die Nutzung und Übertragung von Informationen, die über Google APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff lässt sich jederzeit in den Google-Kontoeinstellungen unter „Drittanbieter-Apps und -Dienste“ widerrufen. Danach wird das lokal gespeicherte Token gelöscht.
